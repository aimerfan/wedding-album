# backend

Python 3.14 + Flask。骨架尚未建立。

## 已定

- **上傳**：照片先傳給 Flask，再由 Flask 存檔。不讓手機直接傳到雲端儲存。
- **照片網址**：一律由 API 回傳，前端不自己組網址。
- **存檔**：包成獨立的一層。開發時存本機磁碟，之後換雲端只換這一層。
- **進入相簿**：會場提供 QR code。
- **賓客身分**：第一次進來時由後端發一個匿名代號，存在手機裡。不做帳號密碼。
  換手機或清除瀏覽器資料會變成新的賓客，這是刻意接受的取捨。
