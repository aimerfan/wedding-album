# 手機實測清單

請用自己的手機，照下面每一項操作一次，看結果是否跟「應該看到」一樣。
不一樣的話，記下**手機型號、用哪個瀏覽器、第幾項**，截圖給我們。

- 測試前請先掃 QR code 進入相簿。
- iPhone 用 Safari，Android 用 Chrome。

## 1. 歡迎頁：字體大小

| # | 操作 | 應該看到 |
| --- | --- | --- |
| 1-1 | 打開歡迎頁 | 「你的名字」上方有一行「Aa 字太小嗎？ 標準／大／特大」 |
| 1-2 | 依序點「大」、「特大」 | 整個畫面的字跟著變大；三個按鈕換到下一行也沒關係，但不會超出畫面 |
| 1-3 | 選「特大」後往下滑 | 「進入相簿」按鈕看得到、按得到 |
| 1-4 | 點回「標準」 | 畫面恢復原本大小 |

## 2. 上傳：新的分類

| # | 操作 | 應該看到 |
| --- | --- | --- |
| 2-1 | 選 1 張照片 → 下一步 | 分類有四個：訂婚・迎娶、宴客、花絮、那些年 |
| 2-2 | 選「那些年」上傳 | 回到首頁後，點上方的「那些年」看得到剛剛那張 |

## 3. 上傳：選照片

| # | 操作 | 應該看到 |
| --- | --- | --- |
| 3-1 | 選 3 張 → 按「＋ 再選」再選 2 張 | 共 5 張，前面選的沒有不見 |
| 3-2 | 按「再選」，選一張剛剛選過的照片 | 不會多出一樣的一格 |
| 3-3 | 按右上角的「清空」 | 照片都不見，下方出現「已清空　復原」 |
| 3-4 | 幾秒內按「復原」 | 照片和勾選都回來 |

## 4. 上傳：一次選超過 30 張

| # | 操作 | 應該看到 |
| --- | --- | --- |
| 4-1 | 一次選超過 30 張 | 只有 30 張被勾起來 |
| 4-2 | 再點一張沒勾的 | 下方短暫出現「已經選了 30 個，先取消其他的才能換這個」 |
| 4-3 | 下一步 → 上傳 | 傳完回到選照片的頁面，剩下沒傳的還在，而且自動勾好 |
| 4-4 | 再按下一步 | 祝福欄是空的，分類跟上一批一樣 |
| 4-5 | 傳完最後一批 | 回到首頁 |
